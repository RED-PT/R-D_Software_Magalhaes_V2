void radio_thread_function ( )

Radio thread main function.

FreeRTOS task entry point for the radio communication thread. Implements the TDMA slot timing and packet transmission/reception loop.

Thread responsibilities:

  • Maintain TDMA slot timing
  • Transmit telemetry packets in appropriate slots
  • Receive and process commands from GS
  • Track synchronization status
  • Update statistics
Note
This function runs as a FreeRTOS task and never returns
Task priority should be high to maintain TDMA timing accuracy
Example
// In main.c, create the radio task
xTaskCreate(radio_thread_function, "Radio", 512, NULL,
configMAX_PRIORITIES - 1, NULL);

void radio_update_sensor_data ( const IMU_t * imu,
const BARO_t * baro,
const BNO_t * bno,
const GPS_t * gps )

Update sensor data for telemetry transmission.

Called by the sensor/telemetry thread to provide latest sensor readings for inclusion in telemetry packets. Data is copied to internal buffers.

Parameters
[in]imuPointer to latest IMU data (can be NULL if unavailable)
[in]baroPointer to latest barometer data (can be NULL if unavailable)
[in]bnoPointer to latest BNO055 data (can be NULL if unavailable)
[in]gpsPointer to latest GPS data (can be NULL if unavailable)
Note
Thread-safe, can be called from sensor thread context
Data is copied internally, caller can reuse pointers after return
Example
// In sensor thread, after reading sensors
IMU_t imu_data;
BARO_t baro_data;
BNO_t bno_data;
GPS_t gps_data;
// Read all sensors...
// Update radio with latest data
radio_update_sensor_data(&imu_data, &baro_data, &bno_data, &gps_data);
