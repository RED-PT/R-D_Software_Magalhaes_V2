Detailed Description

U-Blox GPS Driver and NMEA Parser Implementation.

Author
Tomas Teixeira
Date
October 2025
Version
2.0

Implements NMEA sentence parsing (GGA, RMC) and the U-Blox GPS driver with circular DMA reception and UBX binary protocol configuration. Board-agnostic: UART instance is resolved via config.h macro (UART_UBLOX).
