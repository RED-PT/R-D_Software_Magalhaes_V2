Build a fast telemetry packet.

Populates a fast telemetry packet with current sensor data and FSM state. Applies scaling factors to convert floating-point values to integers. Calculates and appends CRC16 checksum.

Parameters
[out]pktPointer to packet structure to populate
[in]frame_idCurrent superframe counter (0-255)
[in]slot_idCurrent TDMA slot (0-7 for fast packets)
[in]seqPacket sequence number
[in]fsm_ctxPointer to FSM context (cast to void* for decoupling)
[in]imuPointer to current IMU data
[in]baroPointer to current barometer data
[in]bnoPointer to current BNO055 orientation data
[in]last_cmd_seqSequence number of last received command
[in]last_cmd_statusStatus of last command (0=OK, 1=rejected, 2=error)
Returns
Size of the built packet in bytes (37)
Note
Scaling applied:
  • Acceleration: g → mg (multiply by 1000)
  • Gyroscope: dps → 0.01 dps (multiply by 100)
  • Altitude: m → 0.1 m (multiply by 10)
  • Angles: deg → 0.1 deg (multiply by 10)
