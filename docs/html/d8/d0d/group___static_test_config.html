◆ STATIC_TEST_MAX_SAMPLES

#define STATIC_TEST_MAX_SAMPLES   ((STATIC_TEST_HOLD_DURATION_MS / (1000 / STATIC_TEST_SAMPLE_RATE_HZ)) + 20)

Maximum number of data samples that can be stored.

Auto-calculated from STATIC_TEST_HOLD_DURATION_MS and STATIC_TEST_SAMPLE_RATE_HZ so the buffer always fits the full hold phase. A margin of 20 extra slots accounts for timing jitter. For the default values (10 s hold, 20 Hz), this evaluates to 220 samples.
