bool BNO055_Configure ( BNO055_t * dev)

Configure BNO055 operating parameters.

Sets up the sensor with:

  • NDOF mode (full 9-DOF fusion)
  • Normal power mode
  • Default units (degrees, m/s^2)
Parameters
[in]devPointer to initialized driver context
Returns
true if configuration successful
false if communication error
Note
Sensor requires ~650ms to switch to NDOF mode

bool BNO055_ProcessData ( BNO055_t * dev,
BNO_t * output )

Process raw data into engineering units.

Converts raw sensor data to physical units and populates the BNO_t output structure with:

  • Euler angles (degrees)
  • Quaternion (normalized)
  • Acceleration (m/s^2 or mg)
  • Angular rate (dps)
  • Magnetic field (uT)
Parameters
[in]devPointer to driver context with valid raw data
[out]outputPointer to BNO_t structure to populate
Returns
true if data processed successfully
false if invalid parameters
