void telemetry_thread_function ( )

Telemetry Thread Entry Point.

Main function for the telemetry data aggregation thread. This function:

  1. Receives sensor data from queue_to_telemetry
  2. Caches the latest reading for each sensor type
  3. Periodically (20 Hz) calls radio_update_sensor_data() to provide the radio thread with current sensor values

Design Note: This thread decouples sensor sampling rates from telemetry rates. Sensors may update at different frequencies (IMU at 416 Hz, GPS at 1 Hz), but telemetry always has the most recent data available.

Note
Does not directly handle radio - that's the Radio thread's job.
