Detailed Description

IMU data structure (ASM330LHHX 6-axis sensor).

Contains accelerometer and gyroscope readings from the ASM330LHHX 6-axis inertial measurement unit.

Note
Accelerometer units: g (1g = 9.81 m/s^2)
Gyroscope units: degrees per second (dps)
