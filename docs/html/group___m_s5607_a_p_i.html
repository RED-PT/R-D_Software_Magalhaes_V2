bool MS5607_Configure ( MS5607_t * dev)

Configure MS5607 and read calibration data.

Resets the sensor and reads factory calibration coefficients from PROM. Must be called before any pressure readings.

Parameters
[in]devPointer to initialized driver context
Returns
true if configuration successful
false if communication error or invalid calibration data

◆ MS5607_ReadTemperatureandPressure()

bool MS5607_ReadTemperatureandPressure ( MS5607_t * dev,
BARO_t * output )

Read temperature and pressure (blocking).

Performs a complete measurement cycle:

  1. Start temperature conversion, wait, read
  2. Start pressure conversion, wait, read
  3. Apply temperature compensation
  4. Calculate altitude using standard atmosphere
Parameters
[in]devPointer to configured driver context
[out]outputPointer to BARO_t structure to populate
Returns
true if reading successful
false if communication error
Note
Blocking function, takes ~20ms for both conversions
Altitude is relative to standard atmosphere (1013.25 mbar)
