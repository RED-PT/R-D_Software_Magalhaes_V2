Detailed Description

Low-level SD card driver over SPI for FatFS.

Provides the disk I/O layer (disk_initialize, disk_read, disk_write, disk_ioctl) that FatFS calls internally. Communication uses the SPI peripheral defined by HSPI_SDCARD in fatfs_sd.h / config.h.

SPI Baud Rate Switch

SD card initialisation must run at a slow SPI clock (<=400 kHz per SD spec). After successful initialisation, if the board's config.h defines SD_SPI_PRESCALER_FAST, the prescaler is lowered to increase throughput for subsequent read/write operations. On the Buzz V4 (H743) this is SPI_BAUDRATEPRESCALER_4; on the F446ZE dev board the macro is not defined so the init prescaler is kept.

Note
Based on elm-chan's generic MMC/SD SPI driver.
