void sensors_thread_function ( void * argument)

Sensor thread main function.

FreeRTOS task entry point for the sensor management thread. Handles sensor data acquisition using a combination of:

  • Interrupt-driven reads (IMU, magnetometer)
  • Timer-driven polling (barometer, BNO055)
  • Continuous DMA (GPS)
Parameters
[in]argumentFreeRTOS task argument (unused)
Note
This function runs as a FreeRTOS task and never returns

◆ sensors_thread_init()

void sensors_thread_init ( void )

Initialize all sensor hardware.

Initializes all sensor devices and configures their operating modes. Must be called before starting the sensor thread.

Initialization sequence:

  1. ASM330LHHX (IMU) - SPI_IMU_BARO
  2. MMC5983MA (Magnetometer) - SPI_MAG
  3. MS5607 (Barometer) - SPI_IMU_BARO
  4. BNO055 (9-DOF) - I2C_BNO
  5. UBLOX GPS - UART_UBLOX
Note
Assumes HAL peripheral handles are already initialized
