◆ PWM_DebugTest()

void PWM_DebugTest ( void )

Debug test function for PWM output.

Cycles through MIN/MID/MAX duty cycles on ESC PWM output. Use oscilloscope to verify output.

Two compile-time variants exist, selected by the radio interface macro in config.h:

  • RADIO_INTERFACE_UART (NUCLEO-F446ZE): Tests PC6 as GPIO then as TIM3_CH1 PWM. Uses LD1/LD2 LEDs as visual indicators. Board-specific register access (TIM3->CCR1, GPIO_AF2_TIM3, etc.).
  • RADIO_INTERFACE_SPI (Buzz V4 / H743): Generic test using the config.h PWM_ESC_* macros. No board-specific pin references.
