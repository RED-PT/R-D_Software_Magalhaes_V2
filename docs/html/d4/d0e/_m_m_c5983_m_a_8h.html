Detailed Description

MMC5983MA 3-axis magnetometer driver for the Magalhaes Flight Computer.

Author
Tomas Teixeira
Date
October 2025

This driver provides an interface to the MEMSIC MMC5983MA high-performance 3-axis magnetometer for heading/compass applications.

Features

  • 3-axis magnetic field measurement
  • 18-bit resolution (0.0625 mGauss/LSB)
  • Full scale range: +/-8 Gauss
  • SPI interface up to 10 MHz (connected via SPI_MAG; see config.h)
  • Automatic SET/RESET for offset elimination
  • DMA-based data transfer
  • Supports multiple board targets (F446ZE Nucleo uses SPI3, H743ZI Buzz V4 uses SPI6)

Usage

MMC5983MA_t mag;
MAG_t data;
MMC5983MA_Init(&mag, &hspi1);
MMC5983MA_Configure(&mag);
// Triggered by data ready or timer
MMC5983MA_StartReadDMA(&mag);
// After DMA complete
MMC5983MA_ParseDMABuffer(&mag);
MMC5983MA_ProcessData(&mag, &data);
