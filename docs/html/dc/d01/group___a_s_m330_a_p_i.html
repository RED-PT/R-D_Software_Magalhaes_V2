◆ ASM330LHHX_Configure()

bool ASM330LHHX_Configure ( ASM330LHHX_t * dev)

Configure ASM330LHHX operating parameters.

Sets up the sensor with default configuration:

  • Accelerometer: +/-16g range, 416 Hz ODR
  • Gyroscope: +/-2000 dps range, 416 Hz ODR
  • Data ready interrupt enabled on INT1
Parameters
[in]devPointer to initialized driver context
Returns
true if configuration successful
false if communication error
Precondition
ASM330LHHX_Init() must have been called successfully

  • Angular rate: degrees per second (dps)

◆ ASM330LHHX_StartReadDMA()

bool ASM330LHHX_StartReadDMA ( ASM330LHHX_t * dev)

Start DMA read of sensor data.

Initiates a non-blocking DMA transfer to read all sensor registers (accelerometer, gyroscope, temperature) in a single burst.

Parameters
[in]devPointer to driver context
Returns
true if DMA transfer started
false if SPI busy or error
Note
Call ASM330LHHX_ParseDMABuffer() after DMA complete interrupt
