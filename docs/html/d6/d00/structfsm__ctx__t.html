Detailed Description

FSM Context - main flight computer state structure.

This is the central data structure for the flight computer, containing all state, configuration, and runtime data.

Note
This structure is global (fsm_ctx) and accessed by multiple threads. Use fsm_get_state() and fsm_set_state() for thread-safe access.
