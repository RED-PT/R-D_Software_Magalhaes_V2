Detailed Description

Barometer data structure (MS5607-02BA).

Contains atmospheric pressure and temperature readings from the MS5607 barometric sensor. Altitude is calculated using the barometric formula.

Note
Altitude calculation requires a reference pressure (sea level or ground)
