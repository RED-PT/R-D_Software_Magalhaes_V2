Detailed Description

9-DOF Absolute Orientation IMU data structure (BNO055)

Contains sensor-fused orientation data from the BNO055 9-axis IMU. Provides both Euler angles and quaternion representations for attitude.

The BNO055 performs on-chip sensor fusion, providing absolute orientation without requiring external processing.
