Detailed Description

SD card logging thread for the Magalhaes Flight Computer.

Author
Tomas Teixeira
Date
October 2025

This module implements the FreeRTOS task responsible for logging flight data to an SD card using the FatFS file system.

Features

  • Continuous data logging at configurable rate
  • CSV format output for easy analysis
  • Automatic file naming with timestamps
  • Pause/resume support for motor tests
  • Graceful shutdown with data flush

Log File Format

Data is logged in CSV format with columns:

  • timestamp_ms, accel_x, accel_y, accel_z, gyro_x, gyro_y, gyro_z
  • pressure, altitude, temperature, latitude, longitude, gps_alt
  • heading, roll, pitch, state, substate

Pause/Resume

SD operations can be paused during motor tests to prevent interference with time-critical operations. Data is buffered and flushed before pausing.
