Detailed Description

Telemetry Data Aggregation Thread Interface.

Author
Tomás Teixeira
Date
2025
Version
2.0

This header defines the interface for the Telemetry thread, which aggregates sensor data and provides it to the Radio thread for transmission to the ground station.

Thread Responsibilities

  • Data Aggregation: Collect latest sensor readings from queues
  • Data Caching: Maintain latest values for each sensor type
  • Radio Interface: Periodically update Radio thread with current data
