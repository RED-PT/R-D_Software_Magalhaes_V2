Detailed Description

FreeRTOS Thread Creation and Resource Definitions.

Author
Tomás Teixeira (texman)
Date
October 6, 2025
Version
2.0

This header defines all FreeRTOS resources (threads, queues, timers) for the Magalhães Flight Computer system. It provides the central point of reference for inter-thread communication and synchronization.

Thread Architecture
