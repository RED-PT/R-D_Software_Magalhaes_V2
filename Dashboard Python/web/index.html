Tests page

            

              
The Tests page exposes four test kinds, each with Manual or Automatic mode.


              
Test kinds

              
    
                
  • STATIC — horizontal-rail motor on load cell. Measures thrust vs throttle.
    • 
                
  • TORQUE — like STATIC plus a moment arm; FC computes torque = thrust · arm.
    • 
                
  • TORQUE CAL — TORQUE plus a servo (α) sweep to characterise torque vs α.
    • 
                
  • GUTTER — tethered vertical climb on a rail; FC controller tracks href in closed loop. Needs healthy baro.
    • 
              


              
Modes

              
    
                
  • Automatic — profile defines the recipe (max throttle, hold time, curve, sweep range). FC executes deterministically.
    • 
                
  • Manual — sliders drive the actuators directly at 10 Hz. Heartbeat: if no slider packet for 1 s, FC auto-aborts.
    • 
              


              
Lifecycle

              
For every test:

              
CONFIGED ──► ARMED ──► COUNTDOWN ──► RUNNING ──► FINISHING ──► DONE
                                            │
                                            ├──► HOLD (manual only — pause)
                                            │
                                            └──► ABORTED (any failure / abort)


              
Pre-conditions

              
    
                
  • Motor calibration (M command) is required before SET PROFILE / ARM accept.
    • 
                
  • GUTTER additionally requires barometer calibration (C command) and a healthy estimator.
    • 
              


              
Manual sliders by kind

              
    
                
  • STATIC, TORQUE — throttle only
    • 
                
  • TORQUE CAL — throttle + α
    • 
                
  • GUTTER — href
    • 
              


              
Heartbeat

              
The green dot in the lifecycle bar is the GS↔FC link health for Manual mode. Green = fresh, orange = stale, red = no packet for > 1 s. When red the FC auto-aborts the test.
